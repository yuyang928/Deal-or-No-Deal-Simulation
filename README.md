# Deal or No Deal Simulator


This is a small Python project that tries to recreate the TV game show **Deal or No Deal**.


I made it as a practice project to learn Python GUI programming with Tkinter. The game is not exactly the same as the real TV show, but it follows most of the basic rules.


## What the program does


- Creates 26 briefcases with random money values

- Lets the player choose one briefcase to keep

- Opens other briefcases during each round

- Shows the remaining values on the screen

- Generates a banker's offer after each round

- Lets the player choose **Deal** or **No Deal**

- Reveals the player's briefcase at the end


## How to Play


1. Start the program.

2. Select one briefcase to keep for yourself.

3. Open the required number of briefcases for the current round.

4. Wait for the banker's offer.

5. Choose:

   - **Deal** to accept the offer and end the game

   - **No Deal** to continue playing

6. Keep playing until you accept a deal or reach the end of the game.
